# ⚡ Быстрый старт - 5 минут

## Команды для копирования (замените YOUR_USERNAME на ваш GitHub username)

```bash
# 1. Перейдите в папку проекта
cd C:\PeriodicTableApp

# 2. Инициализируйте Git
git init

# 3. Настройте Git (замените на свои данные!)
git config user.name "Ваше Имя"
git config user.email "your.email@example.com"

# 4. Добавьте файлы
git add .

# 5. Создайте коммит
git commit -m "Initial commit: Periodic Table iOS App"

# 6. Подключите GitHub (ЗАМЕНИТЕ YOUR_USERNAME!)
git remote add origin https://github.com/YOUR_USERNAME/PeriodicTableApp.git

# 7. Переименуйте ветку
git branch -M main

# 8. Загрузите на GitHub
git push -u origin main
```

## Перед выполнением команд:

1. ✅ Установите Git: https://git-scm.com/download/win
2. ✅ Создайте репозиторий на GitHub: https://github.com/new
   - Название: `PeriodicTableApp`
   - Тип: Public
   - НЕ добавляйте README/gitignore
3. ✅ Замените `YOUR_USERNAME` на ваш GitHub username

## После загрузки:

1. Откройте https://github.com/YOUR_USERNAME/PeriodicTableApp
2. Перейдите во вкладку "Actions"
3. Наблюдайте за автоматической сборкой
4. Через 5-10 минут увидите ✅ или ❌

## Готово! 🎉

Ваше приложение теперь на GitHub с автоматической проверкой сборки на каждый commit!
