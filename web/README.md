# Веб-приложение "Таблица Менделеева"

Интерактивное веб-приложение для изучения таблицы Менделеева. Работает на любом устройстве, включая iPhone.

## 🚀 Как открыть на iPhone

### Вариант 1: Локально (для тестирования)

1. Откройте файл `index.html` в браузере на компьютере
2. Проверьте, что все работает

### Вариант 2: Через GitHub Pages (рекомендуется)

1. Загрузите папку `web` на GitHub
2. Включите GitHub Pages в настройках репозитория
3. Откройте ссылку на iPhone в Safari
4. Нажмите "Поделиться" → "На экран Домой"
5. Приложение появится как иконка на главном экране!

### Вариант 3: Через любой хостинг

Загрузите файлы на любой бесплатный хостинг:
- Netlify (netlify.com)
- Vercel (vercel.com)
- GitHub Pages
- Cloudflare Pages

## 🔧 Как добавить больше элементов

Откройте `data.js` и добавьте новые элементы в массив `elements`:

```javascript
{
    id: 21,
    symbol: "Sc",
    name: "Скандий",
    atomicMass: 44.96,
    category: "Переходный металл",
    group: 3,
    period: 4,
    electronConfiguration: "[Ar] 3d¹ 4s²",
    description: "Описание элемента"
}
```

## 📖 Использование

1. **Таблица**: Нажмите на элемент для просмотра деталей
2. **Поиск**: Введите название, символ или номер элемента
3. **Фильтр**: Выберите категорию для фильтрации
4. **Викторина**: Выберите режим и проверьте свои знания
