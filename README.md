# Periodic Table App

Интерактивное iOS приложение для изучения таблицы Менделеева с минималистичным черно-белым дизайном.

## Возможности

- **Интерактивная таблица Менделеева**: Просмотр всех химических элементов в классической таблице
- **Детальные карточки элементов**: Полная информация о каждом элементе (атомная масса, электронная конфигурация, категория)
- **Поиск и фильтрация**: Быстрый поиск элементов по названию, символу или атомному номеру
- **Викторины**: Три режима викторин для проверки знаний:
  - Угадай элемент по символу
  - Угадай символ по элементу
  - Угадай атомный номер
- **Минималистичный дизайн**: Черно-белая цветовая схема для фокусировки на контенте

## Структура проекта

```
PeriodicTableApp/
├── PeriodicTableApp.swift      # Точка входа приложения
├── ContentView.swift            # Главный экран с TabView
├── Element.swift                # Модель данных элементов
├── ElementDetailView.swift      # Детальная информация об элементе
├── SearchView.swift             # Экран поиска и фильтрации
├── QuizView.swift               # Экран викторин
├── QuizManager.swift            # Логика викторин
└── Theme.swift                  # Цвета и стили приложения
```

## Требования

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## Установка

1. Откройте Xcode
2. Создайте новый проект iOS App
3. Скопируйте все файлы из папки PeriodicTableApp в ваш проект
4. Запустите приложение на симуляторе или устройстве

## Использование

### Просмотр таблицы
- Откройте вкладку "Таблица"
- Нажмите на любой элемент для просмотра детальной информации

### Поиск элементов
- Откройте вкладку "Поиск"
- Введите название, символ или номер элемента
- Используйте фильтр по категориям для уточнения поиска

### Викторины
- Откройте вкладку "Викторина"
- Выберите режим викторины
- Ответьте на 10 вопросов
- Получите результат и начните заново

## Дизайн

Приложение использует строгий минималистичный дизайн:
- Черно-белая цветовая палитра
- Четкие границы и разделители
- Простая типографика
- Интуитивная навигация
- Фокус на контенте без отвлекающих элементов
